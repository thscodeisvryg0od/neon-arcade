# 🕹️ Neon Arcade

**Neon Arcade** is a fast, lightweight, web-based arcade gaming platform featuring neon-themed retro/modern mini-games. Thanks to its Progressive Web App (PWA) support, it can work offline and be installed directly onto mobile and desktop devices.

---

## ✨ Features

* 🎨 **Neon & Retro Design:** Dynamic neon glow effects and a sleek dark mode interface.
* 📱 **PWA (Progressive Web App) Support:** Can be installed on mobile/desktop devices and played offline (`sw.js` & `manifest.json`).
* ⚡ **Fast & Lightweight:** Built with pure HTML5, CSS3, and JavaScript — no heavy libraries or external dependencies.
* 🎯 **Fully Responsive:** Seamlessly adapts to all screen sizes and mobile devices.

---

## 📁 Project Structure

```text
neon-arcade/
├── index.html       # Main HTML layout & game interface
├── style.css        # Neon styling, themes, and animations
├── script.js        # Game logic and interactive mechanics
├── manifest.json    # PWA app configuration

🚀 Getting Started

​Since this project runs entirely on the client side, no compilation or complex server setup is required.

1. Clone the repository:

git clone [https://github.com/your-username/neon-arcade.git](https://github.com/your-username/neon-arcade.git)


2. Navigate to the project directory:


cd neon-arcade

Run the app:

Simply open index.html in any modern web browser.
